# heartfall

**Heartfall** is a Minecraft mod that introduces a dynamic health recovery mechanic to PvE combat.
When you defeat hostile mobs, they have a chance to drop floating heart shards that restore your health.

Drop chance is a sliding scale based on the attacker's current health fraction. A player at full health uses the base drop chance (default 12.5%), scaling linearly up to the max drop chance (default 50%) as the player's health approaches zero.
